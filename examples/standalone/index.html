Using Lyricue

  1. Install

    The npm release is coming soon. For now, build and pack from source.

    git clone https://github.com/qianyinshi/lyricue.git
cd lyricue
npm ci
npm run build
npm pack
# In your project:
npm install /path/to/lyricue/lyricue-0.1.0.tgz

  2. Use

    JavaScript
    import { defineLyricsEditor } from 'lyricue';

defineLyricsEditor();
const editor = document.createElement('lyrics-editor');
editor.load({
  audioSrc: '/song.mp3',
  lyrics: 'First line\nSecond line',
  mode: 'tap',
  locale: 'en',
  keyboardScope: 'page',
});
editor.addEventListener('lyrics-save', ({ detail }) => {
  console.log(detail.lyrics);
});
document.querySelector('#app').append(editor);
