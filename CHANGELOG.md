# Changelog

## 0.2.0 — 2026-10-25

- Add versioned editor session snapshots, validation, restoration and session-change events.
- Add phase control and optional scrolling lyrics during the rough pass.
- Preserve active phrases when resuming with Space, stable shortcut focus across locale changes and timeline zoom across stage changes.
- Improve lyric preview rendering, native button keyboard behavior and viewport restoration.
- Turn the playground into a bilingual, responsive app with local project saving, explicit continuation, file handle support, native dialogs and LRC export.
- Update demo audio and lyrics to “月下独酌 · 长乐宫舞”.

The component remains a framework-independent Web Component with no runtime or peer dependencies.
